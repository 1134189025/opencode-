# OpenCode Prompt Enhancer (提示词增强插件)

这是一个为 OpenCode 打造的提示词增强插件。它提供了一个基于 Apple 风格的“液态玻璃态 (Liquid Glassmorphism)”设计的优美图形配置界面，让你能通过调用大语言模型 (LLM) 的 API，将大白话自动转换为专业的提示词。

## ✨ 核心特性

- **🎨 极致优雅的界面**：采用现代化的 Apple 风格设计，运用毛玻璃 (Glassmorphism)、流畅动画与精美排版，提供极佳的视觉与交互体验。
- **🔌 灵活的 API 配置**：
  - 支持自定义 API 接口地址 (如 OpenAI、第三方或本地模型代理)。
  - 支持配置 API 密钥 (API Key)。
  - 支持自定义模型名称 (如 `gpt-4o-mini`, `claude-3-5-sonnet` 等)。
- **🛠️ 自定义核心指令**：可自定义 System Prompt，定义 AI 如何处理你的输入（如规定输出的 Markdown 格式、语气、专业领域等）。
- **🧪 连通性测试**：内置一键测试连接状态功能，方便快速排查 API 配置是否正确。
- **⚙️ 便捷的开关控制**：提供全局主开关，一键掌控插件是否介入工作。

## 🚀 日常使用与启动

本插件包含一个独立的可视化配置面板。**你不需要在特定的目录下打开它，无论你把插件放在电脑的哪个位置，都可以正常运行和加载。**

### 启动配置面板
在插件根目录（例如 `.opencode\plugins\`）下，找到 `start-gui.bat` 文件：
1. **直接双击** 运行 `start-gui.bat`。
2. 脚本会自动检测你系统是否安装了 `bun` 或 `node.js`，并在后台启动一个微型本地服务。
3. 随后，它会自动在浏览器中打开配置面板（默认地址：`http://localhost:19827`）。
4. （如果你的系统既没有 bun 也没有 Node.js，脚本会以离线模式直接在浏览器中打开 HTML，依然可用）

### 配置项说明
1. 打开界面的 **"提示词优化"** 开关。
2. 在 **API 配置** 卡片中，填入你的 `接口地址` (通常是以 `/v1/chat/completions` 结尾的接口，或具体按你使用的 API 服务商要求填写)。
3. 输入你的 `API 密钥` 和想使用的 `模型名称`。
4. 在 **核心系统指令** 中，写入你对 AI 的调教指令（例如："你是一个资深的程序员，帮我把接下来的口语化描述转化为精确的代码需求文档..."）。
5. 点击 **保存设置**。之后在 OpenCode 对应输入框中输入大白话，即可享受提示词增强。

## 📁 主要文件结构

- `start-gui.bat`: **启动脚本，负责拉起配置面板。**
- `config-server.ts`: 本地配置同步服务器代码。
- `gui/index.html`: 配置页面的 HTML。
- `gui/style.css`: 样式代码。
- `gui/app.js`: 页面交互逻辑。
- `prompt-enhancer-config.json` *(运行时生成)*: 保存你的当前配置数据，与插件在同一目录自动产生。
